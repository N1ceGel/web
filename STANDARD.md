# STANDARD.md — Стандарт разработки лендинга

> Этот документ — технический стандарт и одновременно контракт требований для страницы проекта «Цифровые дни информирования» (платформа «РЦК»).  
> Здесь собраны правила верстки, сетка, цвета, описание всех 6 компонентов и критерии, по которым мы проверяем готовый результат перед сдачей.

---

## Постановка задачи (Prompt-контракт)

- **Ты веб-разработчик.**
- **Заказчик:** Корпоративная платформа «РЦК» (оргкомитет проекта «Цифровые дни информирования» — проведение информационных онлайн-встреч для территориально распределенных филиалов с AI-протоколированием и единым архивом).
- **Цель страницы:** Оставить заявку на проведение информационной встречи для филиала / позвонить в оргкомитет.
- **Аудитория:** Руководители филиалов, докладчики и сотрудники предприятий из разных городов. Основные устройства: смартфоны (390px) и корпоративные ПК (1440px).
- **Критерии готовности:**
  1. Открывается на телефоне 390px без горизонтальной прокрутки.
  2. Кнопка «Позвонить» набирает номер `+7 (800) 350-20-40` через ссылку `tel:`.
  3. Форма отправляет уведомление о заявке на электронную почту, указанную пользователем в заявке.
  4. Lighthouse mobile: Performance и Accessibility не ниже 90.
- **Стек:** один HTML-файл + CSS + JS, без сборщиков (No Webpack/Vite, No npm).
- **Ограничение:** Собирай только из компонентов `STANDARD.md`. Сначала задай мне до 5 уточняющих вопросов, потом делай.

## 1. Адаптивность и поведение на экранах

Главная задача верстки — сайт должен одинаково уверенно смотреться и на рабочем мониторе, и на экране смартфона, когда человек открывает ссылку на бегу.

- **Контрольные экраны для тестирования:**
  - `390px` — основной мобильный профиль (размер экранов современных iPhone 14–16 и большинства Android-смартфонов).
  - `768px` — планшетный режим (iPad).
  - `1440px` — классический офисный монитор или ноутбук.

- **Железное правило: никакого горизонтального скролла:**
  - Страница на экранах любой ширины (от 320px до широкоформатных) скроллится только строго по вертикали.
  - Обязательный базовый CSS-сброс:
    ```css
    *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; }
    html, body { width: 100%; overflow-x: hidden; }
    img, svg, video { max-width: 100%; height: auto; display: block; }
    ```
  - **Защита от «скрытого переполнения» во вложенных сетках (`min-width: 0`):**  
    В CSS Grid и Flexbox длинный контент или дочерние кнопки могут распирать карточки шире экрана (дефолтное поведение `min-width: auto`). Чтобы блок архива `.demo-layout`, плеер и табы не выталкивали страницу вбок на мобилках, для всех дочерних колонок обязательно прописываем `minmax(0, 1fr)` и `min-width: 0`.
  - **Перенос длинных слов:** Для всех текстовых блоков и списков задаем `word-break: break-word; overflow-wrap: break-word;`, чтобы сложные технические термины и ссылки не срезались краем экрана.
  - **Удобство для пальцев (Touch Targets):** Все кнопки, ссылки и поля ввода на мобильном имеют размер интерактивной зоны не менее `44×44px`, чтобы по ним было легко попадать одной рукой.

## 2. Сетка, отступы и ритм страницы

Чтобы страница читалась легко и выглядела аккуратно, верстаем по 8-пиксельной модульной сетке:

- **Шаг модульной шкалы:** `8px` (значения: 4px, 8px, 16px, 24px, 32px, 48px, 64px).
- **Максимальная ширина контента:** `1200px` с центрированием через `margin: 0 auto;` — на широких экранах контент не «размазывается» по краям.
- **Поля по бокам контейнера (padding):**
  - Смартфоны (< 768px): комфортные `16px`, чтобы полезное место не съедалось.
  - Планшеты (768px–1024px): `24px`.
  - Десктопы (> 1024px): просторные `32px`.
- **Поведение колонок:** на мобилках всё выстраивается в одну удобную колонку, на планшетах разбивается на 2, на компьютерах — на 3–4 колонки.

## 3. Типографика и корпоративная палитра

Никаких тяжелых шрифтов с Google Fonts — страница должна открываться мгновенно даже при медленном мобильном интернете или корпоративных ограничениях.

- **Шрифты (системный стек для максимального Lighthouse 95+):**
  - Основной текст и заголовки: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Arial, sans-serif` (нативно использует шрифты системы — San Francisco на iOS/macOS, Segoe UI на Windows).
  - Моноширинный шрифт (для таймкодов и бейджей): `ui-monospace, SFMono-Regular, "Consolas", monospace`.

- **Размеры текста:**
  - `H1` (главный заголовок): 38px на десктопе / 28px на телефоне, жирный (700), межстрочный интервал 1.2.
  - `H2` (заголовки секций): 28px на десктопе / 22px на телефоне, жирный (700).
  - `H3` (карточки): 18px, полужирный (600).
  - Основной текст (`body`): 16px, комфортная высота строки 1.5–1.6.
  - Подписи и бейджи (`caption`): 13px, полужирный (500).

- **Цвета (фирменный стиль платформы «РЦК»):**
  - Основной синий: `#0052CC` (кнопки, активные акценты).
  - Синий при наведении: `#0747A6`.
  - Светло-голубой фон бейджей: `#E9F2FF`.
  - Фон страницы: чистый белый `#FFFFFF`.
  - Фон чередующихся блоков: мягкий серый `#F4F6F9`.
  - Заголовки (высокий контраст): глубокий темно-синий `#091E42`.
  - Основной текст: темно-серый `#172B4D` (отличная читаемость без усталости глаз).
  - Второстепенный текст и подсказки: `#5E6C84`.
  - Тонкие границы карточек: `#DFE1E6`.
  - Зеленый цвет успеха: `#00875A` (статусы, успешная отправка формы).
  - Красный бейдж: `#DE350B` (индикатор прямого эфира).

## 4. Компоненты страницы (6 ключевых блоков)

Страница собирается из 6 самодостаточных блоков, закрывающих весь сценарий пользователя:

1. **Шапка (`header`):**
   - Логотип с отметкой «РЦК | Дни информирования» (на мобилках прячем длинный подзаголовок, чтобы не перегружать шапку).
   - Навигационные ссылки («Возможности», «Демо архива», «Подать заявку») — на экранах меньше 900px скрываются, освобождая место.
   - Кнопка быстрого звонка: `<a href="tel:+78003502040">...</a>`. На компьютере виден полный номер `8 (800) 350-20-40`, а на телефоне (< 768px) номер превращается в компактную кнопку с иконкой трубки (40×40px).
   - Кнопка действия «Запланировать встречу» (ведет скроллом к форме): на мобильных экранах сокращается до емкого «Встреча». Все три элемента шапки аккуратно стоят в одну строчку без переносов.

2. **Первый экран (`hero`):**
   - Бейдж: «Для всех филиалов и подразделений предприятия».
   - Заголовок H1: «Информационные встречи без потерь: онлайн-участие, архив и AI-выжимка».
   - Понятный лид-текст о едином пространстве встреч на базе LiveKit для распределенных команд.
   - Две целевые кнопки: «Подать заявку на встречу» (основная) и «Смотреть демо архива» (второстепенная).
   - Карточки ключевых метрик: 100% охват филиалов, AI-саммари за 1 минуту, автопротокол присутствия.

3. **Сетка преимуществ (`features`):**
   - 4 лаконичные карточки:
     1. *Удаленное подключение (LiveKit WebRTC)* — стабильная связь между городами без задержек.
     2. *Потоковая транскрибация* — автоматический перевод речи выступающего в текст в реальном времени.
     3. *AI-выжимка тезисов* — умное краткое содержание с привязкой к слайдам.
     4. *Защищенный архив* — видео, протоколы и файлы хранятся во внутреннем контуре предприятия.

4. **Демо карточки встречи (`demo-archive`):**
   - Живой интерактивный блок прошедшего мероприятия («Итоги III квартала филиальной сети»).
   - Адаптивная двухколоночная сетка: слева плеер, справа вкладки с материалами (на смартфоне перестраивается в одну колонку).
   - Имитация видеоплеера с кнопкой Play/Pause и таймкодом.
   - Переключаемые вкладки (Tabs) с мягким горизонтальным свайпом пальцем:
     - *Таб 1: AI-выжимка* (3 главных тезиса с автопереносом длинных слов).
     - *Таб 2: Таймкоды* (список слайдов — клик перематывает счетчик плеера).
     - *Таб 3: Материалы* (кнопка скачивания презентации со статусом «Загрузка»).
   - Информационная плашка: «142 участника онлайн • Протокол сформирован».

5. **Форма заявки (`booking-form`):**
   - Заголовок: «Организовать информационную встречу филиала».
   - Поля ввода:
     - ФИО организатора / докладчика (`input[type="text"]`, обязательное).
     - Филиал / Площадка (`select`, обязательное).
     - Тема встречи (`input[type="text"]`, обязательное).
     - Формат встречи (`select`: Онлайн-ВКС / Гибридный).
     - Электронная почта для подтверждения (`input[type="email"]`, обязательное).
   - Кнопка отправки: «Отправить заявку и получить ссылку на почту».
   - Интеграция с почтой: реальная доставка письма заявителю через веб-приложение Google Apps Script (`MailApp.sendEmail`). Запрос отправляется асинхронно через `fetch()` в режиме `no-cors` с заголовком `text/plain`, без блокировок браузера.
   - После отправки форма скрывается и показывает экран успеха со сгенерированным номером тикета (например, `№ ИВ-2026-482`) и точным адресом почты, куда ушло письмо.

6. **Подвал (`footer`):**
   - Описание архитектуры: «Решение в закрытом контуре РЦК (LiveKit + Django + AI-модуль)».
   - Кликабельный контакт горячей линии: `<a href="tel:+78003502040">8 (800) 350-20-40</a>` и служебная почта.
   - Ссылки на корпоративные регламенты и копирайт команды разработчиков.
